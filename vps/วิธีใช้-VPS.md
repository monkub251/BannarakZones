ใช้เวลาประมาณ 20 นาที ไม่ต้องรู้ Linux มาก่อน

---

## 1. ซื้อ VPS

ที่ [cloudvps.in.th](https://cloudvps.in.th/) — แนะนำ

| แพ็ก | RAM | vCPU | ราคา/เดือน | เหมาะกับ |
|---|---|---|---|---|
| Cloud VPS 2 | 4GB | 2 | **฿299** | เริ่มต้น คนเล่น 20-30 คน |
| Cloud VPS 4 | 8GB | 4 | ฿899 | คนเล่น 100 คน |

**ตอนสั่งซื้อเลือก** ระบบปฏิบัติการเป็น **Ubuntu 24.04** (ถ้าไม่มีเลือก Ubuntu 22.04 ก็ได้)

เริ่มที่ 4GB ก่อนได้ อัปเกรดทีหลังไม่ต้องย้ายข้อมูล

ซื้อแล้วเขาจะส่งมาให้ 3 อย่าง: **IP · ชื่อผู้ใช้ (root) · รหัสผ่าน**

## 2. เชื่อมต่อเข้า VPS

Windows 10/11 มีมาให้แล้ว ไม่ต้องลงโปรแกรม

1. กดปุ่ม Windows พิมพ์ `powershell` แล้วกด Enter
2. พิมพ์คำสั่งนี้ (เปลี่ยน `123.45.67.89` เป็น IP ที่เขาส่งมา)

```
ssh root@123.45.67.89
```

3. ครั้งแรกจะถามว่า `Are you sure you want to continue connecting?` → พิมพ์ `yes` กด Enter
4. ใส่รหัสผ่าน — **ตอนพิมพ์จะไม่มีอะไรขึ้นบนจอเลย เป็นเรื่องปกติ** พิมพ์ให้จบแล้วกด Enter

เห็นข้อความแบบ `root@vps:~#` = เข้าได้แล้ว

---

## 3. รันสคริปต์ติดตั้ง

วางคำสั่งนี้ทั้งก้อน กด Enter

```
curl -fsSL -o setup.sh https://raw.githubusercontent.com/monkub251/BannarakZones/main/vps/setup.sh && sudo bash setup.sh
```

> ถ้าคำสั่งนี้ใช้ไม่ได้ (ยังไม่ได้อัปไฟล์ขึ้น GitHub) ให้เปิดไฟล์ `setup.sh` ด้วย Notepad
> คัดลอกทั้งไฟล์ แล้วบน VPS พิมพ์ `nano setup.sh` → วาง → กด `Ctrl+X` → `Y` → Enter
> จากนั้นพิมพ์ `sudo bash setup.sh`

รอประมาณ 5-10 นาที จะเห็นข้อความสีเขียวบอกว่าทำอะไรอยู่

**ถ้ามีสีแดงขึ้น** สคริปต์จะหยุดทันทีและบอกว่าพังตรงไหน — คัดลอกข้อความมาถามได้

---

## 4. เสร็จแล้วจะเห็นแบบนี้

```
เซิร์ฟกำลังทำงาน

  ที่อยู่เซิร์ฟ (Java)     123.45.67.89
  ที่อยู่เซิร์ฟ (มือถือ)    123.45.67.89 พอร์ต 19132
  แผงเว็บ                http://123.45.67.89:8765
```

เอา IP นั้นไปใส่ในเกมได้เลย **เพื่อนเข้าได้ทันที ไม่ติด CGNAT อีกแล้ว**

---

## 5. ย้ายของเดิมขึ้นไป

ยังอยู่บน PowerShell เครื่องคุณ (เปิดหน้าต่างใหม่) พิมพ์:

```
scp -r C:\mcserver\plugins\* root@123.45.67.89:/opt/minecraft/plugins/
scp -r C:\mcserver\world root@123.45.67.89:/opt/minecraft/
```

เสร็จแล้วกลับไปหน้าต่าง SSH พิมพ์

```
chown -R minecraft:minecraft /opt/minecraft
systemctl restart minecraft
```

> โลกไฟล์ใหญ่ อาจใช้เวลานาน ถ้าอยากเริ่มโลกใหม่ก็ข้ามบรรทัด world ไปได้

---

## 6. แก้บอทดิสคอร์ด

เปิด `C:\mcserver\discordbot\config.json` แก้บรรทัด

```json
"url": "http://127.0.0.1:8765",
```

เป็น

```json
"url": "http://123.45.67.89:8765",
```

แล้วเปิดบอทใหม่

## คำสั่งที่ใช้บ่อย

| ต้องการ | พิมพ์ |
|---|---|
| ดูว่าเซิร์ฟทำงานอยู่ไหม | `systemctl status minecraft` |
| ดู log สด ๆ | `journalctl -u minecraft -f` (ออกด้วย `Ctrl+C`) |
| รีสตาร์ตเซิร์ฟ | `systemctl restart minecraft` |
| ปิดเซิร์ฟ | `systemctl stop minecraft` |
| เปิดเซิร์ฟ | `systemctl start minecraft` |
| สำรองข้อมูลเดี๋ยวนี้ | `mc-backup` |
| ดูพื้นที่ดิสก์ | `df -h` |

**สั่งคำสั่งในเกม** ใช้ `/admin` ในเกม หรือแผงเว็บพอร์ต 8765

## สคริปต์ทำอะไรให้บ้าง

- ลง **Java 25** และ**ตรวจสอบว่าได้ 25 จริง** ถ้าไม่ใช่จะหยุดทันที ไม่ปล่อยให้พังทีหลัง
- โหลด **Paper 26.3** และเช็กว่าไฟล์ที่ได้เป็น .jar จริง
- โหลด **ปลั๊กอิน BannarakZones ตัวล่าสุด** จาก GitHub ของคุณ
- โหลด **Geyser + Floodgate** ให้มือถือเข้าได้
- **คำนวณแรมให้อัตโนมัติ** ตามขนาดเครื่อง เหลือให้ระบบ 25% หรือ 1GB
- เปิดพอร์ต **25565/tcp · 19132/udp · 19133/udp · 8765/tcp** และปิดที่เหลือทั้งหมด
- **เปิดเองตอนบูต · รีสตาร์ตเองถ้าล่ม**
- **สำรองข้อมูลทุกวันตี 4** เก็บย้อนหลัง 7 วัน
- รันเซิร์ฟด้วยผู้ใช้ `minecraft` **ไม่ใช่ root** ถ้าโดนเจาะจะเสียหายน้อยกว่า
