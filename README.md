# BannarakZones

ปลั๊กอินตัวเดียวที่ถือระบบทั้งเซิร์ฟ เขียนขึ้นเองสำหรับ **Paper 26.3** ไม่ได้ก็อปของใคร

ทุกอย่างแก้ได้จากไฟล์ใน `plugins/BannarakZones/` แล้วพิมพ์ `/zone reload` ในเกม ไม่ต้องรีสตาร์ท

## เขตป้องกัน

วาง **บีคอน** ลงพื้น เกิดเขตรัศมี 16 (32x32) รอบตัวมันทันที

**คลิกขวาที่บีคอน** เปิดเมนูจัดการ: ขยายเขต, ซื้อช่องเขตเพิ่ม, เพิ่ม/ลบสมาชิก (เลือกจากหัวคนที่ออนไลน์), เปิดปิด PvP, เปิดปิดระเบิด, เปิดปิดข้อความเข้าออก, ดูขอบเขต, ลบเขต

**กัน** ทุบ/วางบล็อก, เปิดหีบประตูเตา, ตีกัน, ระเบิด, ไฟลาม, เทน้ำเทลาวา, พิสตันดันข้ามเขต, ตีสัตว์และกรอบรูป — **กันเต็มความสูงโลก** ขุดจากข้างบนหรือข้างล่างเข้ามาไม่ได้

ลบเขตแล้วบีคอนคืนเข้ากระเป๋า เขตคนละคนต้องห่างกันอย่างน้อย 4 บล็อก

## ดันเจียน

ลงได้ **3-5 คน** มิติแยก **50 เวฟ** ยิ่งลึกมอบยิ่งเยอะและยิ่งอึด

- เวฟ 49 **บอสรอง** · เวฟ 50 **บอสใหญ่** ที่เรียกลูกน้องมาเรื่อย ๆ
- นับถอยหลัง 10 วินาทีให้เตรียมของ **เตรียมได้รอบเดียว**
- **ตายแล้วออกทันที** ไม่ให้กลับเข้า ถ้าตายหมดคือแพ้
- ผ่านแต่ละเวฟได้เงิน ผ่านครบ 50 ได้เงินก้อนใหญ่ + ประกาศทั้งเซิร์ฟ
- **คูลดาวน์ 10 ชั่วโมง** นับทุกคนที่เข้า ไม่ว่าจะแพ้หรือชนะ

ตั้งจุดเริ่ม: ยืนในมิติดันเจียนแล้วพิมพ์ `/dungeon setspawn`

## ภารกิจ

16 อย่างให้มาแล้ว — เดิน วิ่ง กระโดด พายเรือ ว่ายน้ำ ขี่ม้า บินเอลิตร้า ตัดไม้ ขุดหิน ล่าเพชร ล่าซอมบี้ ล่าครีเปอร์ ตกปลา เลี้ยงสัตว์ ค้าขาย เวลาเล่น

แต่ละอย่างมีหลายขั้น ผ่านขั้นไหนได้เงินขั้นนั้นทันที ความคืบหน้าอ่านจากสถิติของเกมเอง เลยนับย้อนหลังให้ด้วย

เพิ่มภารกิจใหม่ได้ใน `missions.yml` ใส่ชื่อสถิติของ Minecraft แล้วไล่ขั้นเอา

---

## เมนู

`menu.yml` คุมทุกหน้า แต่ละช่องตั้งได้ว่าใช้ไอคอนอะไร เขียนว่าอะไร กดแล้วทำอะไร

ปุ่มสั่งได้ทั้งคำสั่งในนามผู้เล่น (`shop`), คำสั่งในนามเซิร์ฟ (`console:give <player> bread 1`), เปิดเมนูอื่น (`open:help`), ส่งข้อความ, เล่นเสียง, ปิดเมนู

ตัวแปรที่ใช้ได้: `<player>` `<money>` `<zones>` `<slots>` `<homes>`

## ยศ

7 ยศ — ส่วนใหญ่เลื่อนอัตโนมัติตามเวลาเล่น เงิน และจำนวนภารกิจที่ทำครบ อีกสองยศซื้อด้วยเงินในเกม

แต่ละยศมีชื่อหน้าชื่อในแชทและสิทธิ์ของตัวเอง เช่น จำนวนบ้านที่ตั้งได้ ปลั๊กอินแจกสิทธิ์ให้เอง ไม่ต้องพึ่งตัวอื่น

## ไอเทมของเซิร์ฟ

`items.yml` ประกาศของที่สวมทับไอเทมปกติ ใส่เลข model data ให้ตรงกับ resource pack ที่ปั้นจาก Blockbench/Blender ได้ พร้อมชื่อ คำบรรยาย มนตร์ และค่าสเตตัสจริง (พลังโจมตี เกราะ หัวใจ ความเร็ว)

ให้ของ: `/citem give <id> <ชื่อผู้เล่น> [จำนวน]`

> **ยังไม่ได้ทำ:** ตัวสร้าง resource pack อัตโนมัติ ตอนนี้ต้องทำ pack เองแล้วให้ผู้เล่นโหลด

---

## กล่องสุ่ม

ตั้งบล็อกไหนก็ได้เป็นกล่อง: มองบล็อกแล้วพิมพ์ `/crate set <ชื่อกล่อง>`

แจกกุญแจ: `/crate key <ชื่อกล่อง> <ผู้เล่น> [จำนวน]` — กุญแจเป็นไอเทมจริงที่ฝังรหัสกล่องไว้ เปลี่ยนชื่อไอเทมมาหลอกไม่ได้

ถือกุญแจคลิกขวาที่กล่อง = สุ่ม มีวงล้อหมุนให้ดู ของหายากประกาศทั้งเซิร์ฟ ถ้าไม่มีกุญแจ คลิกแล้วเห็นรายการของกับเปอร์เซ็นต์

## สิ่งที่ต้องมีเพิ่ม

- **AuthMe** — ระบบล็อกอินสำหรับเซิร์ฟ offline-mode
