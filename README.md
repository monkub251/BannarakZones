# BannarakZones

ปลั๊กอินเขตป้องกันสำหรับ Paper 26.3 — วางบีคอนแล้วเกิดเขตป้องกันรอบตัวมัน

## ใช้ยังไง

- **วางบีคอน** → เกิดเขตรัศมี 16 (พื้นที่ 32x32) รอบบล็อกนั้น
- **คลิกขวาที่บีคอน** → เปิดเมนูจัดการทุกอย่าง
- **ทุบบีคอน** → ลบเขต (เฉพาะเจ้าของ)

## ในเมนูมีอะไร

| ปุ่ม | ทำอะไร |
|---|---|
| ขยายเขต | ซื้อรัศมีเพิ่ม 16 → 24 → 32 → 48 |
| ซื้อช่องเขตเพิ่ม | มีได้หลายเขต ราคาเพิ่มเท่าตัวทุกช่อง |
| สมาชิก | เพิ่ม/ลบเพื่อนที่สร้างในเขตได้ เลือกจากหัวคนที่ออนไลน์ |
| PvP | เปิด/ปิดการตีกันในเขต |
| ระเบิด | เปิด/ปิด TNT และครีเปอร์ |
| ข้อความเข้า/ออก | เปิด/ปิดแจ้งเตือนตอนคนเดินเข้าออก |
| ดูขอบเขต | โชว์เส้นขอบเขตด้วยอนุภาค |
| ลบเขต | ลบเขตทิ้ง |

## กันอะไรบ้าง

ทุบ/วางบล็อก, เปิดหีบประตูเตา, ตีกัน, ระเบิด, ไฟลาม, เทน้ำเทลาวา, พิสตันดันข้ามเขต,
ตีสัตว์และกรอบรูป — ทั้งหมดนี้กัน **เต็มความสูงโลก** ขุดลงมาจากข้างบนหรือเจาะขึ้นมาจากข้างล่างไม่ได้

## คำสั่ง

- `/zone` — เปิดเมนู (ถ้ายืนอยู่ในเขตตัวเอง)
- `/zone info` — ดูว่าตรงนี้เป็นเขตของใคร
- `/zone list` — ดูเขตทั้งหมดของตัวเอง
- `/zone reload` — โหลด config ใหม่ (แอดมิน)

## ตั้งค่า

แก้ `plugins/BannarakZones/config.yml` แล้วพิมพ์ `/zone reload` — ราคา รัศมี ข้อความ เสียง แก้ได้หมด
